Course Descriptions

The Software Development program at Wayne Community College provides us students with a strong foundation in programming, web development, database management, and computer systems. The courses listed below contributed to the development of technical skills used throughout this portfolio.

Software Development Courses

Course Title Concepts Covered
CSC 151/251 Java and Advanced Java Programming Programming fundamentals, variables, loops, conditional statements, problem solving, Object-oriented programming, classes, methods, GUI applications
CSC 121 Python Programming Python syntax, functions, file handling, automation
WEB 182 PHP Programming HTML, CSS, PHP, website structure, responsive design
CTS 120 Hardware/Software Support Computer hardware, operating systems, troubleshooting
CTI 110 IT Fundamentals Introduction to IT concepts, networking, security
DBA 120 Database Programming I SQL, database design, queries, data relationships
NOS 120 Linux Single User Linux system navigation, file management, access permissions, command-line tools, shell environments, pattern matching, I/O redirection, networking, and system customization
WEB 151 Mobile Application Development Mobile app design, development frameworks, user interface design

Sample Course Work

Java Coin Toss Program

Course: CSC 251 – Advanced Java Programming

Time to Complete: Approximately 2 hours

This project demonstrates the use of Java programming concepts such as random number generation and program logic. The program simulates a coin toss and displays the result to the user.

This example was included in the portfolio because it demonstrates an understanding of programming fundamentals and problem-solving skills developed during the course.

Python Employee Management System

Course: CSC 121 – Python Programming

Time to Complete: Approximately 4 hours

This Python program allows users to manage employee information by adding, updating, searching, and deleting employee records stored in a JSON file.

This project demonstrates the ability to structure programs, work with data storage, and implement user interaction through command-line input.

Tri and Succeed Sports Website

Course: WEB 182 – PHP Programming

Time to Complete: Approximately 6 hours

This project involved building a multi-page website using HTML and CSS. The site includes navigation links, structured content, and styled layouts for pages related to running, cycling, and swimming.

This project was selected for the portfolio because it demonstrates skills in webpage structure, navigation design, and visual presentation.
